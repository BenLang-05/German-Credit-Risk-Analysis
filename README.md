# German Credit Risk Analysis

A data analysis project exploring the German Credit dataset using Python and Jupyter Notebook.
The project investigates borrower characteristics through statistical analysis, visualisation, and data anonymisation techniques.

## Features
Dataset exploration and inspection,
Descriptive statistical analysis,
Data visualisation using charts and histograms,
Age generalisation for anonymisation,
Suppression of sensitive attributes,
Analysis of borrower demographics and loan purposes,
Creation of an anonymised dataset

## Technologies Used
Python,
Jupyter Notebook,
Pandas,
NumPy,
Matplotlib

## Project Overview
This project analyses the German Credit dataset to gain insights into borrower characteristics and credit-related information. 
The analysis includes exploratory data analysis, visualisation of key attributes, and the application of anonymisation techniques to protect sensitive information while preserving the usefulness of the data.
